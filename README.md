# Nuvio

An Android home for your visual novels and RPGs, designed for both handheld controllers and touchscreens.

This repository hosts release downloads and playtester feedback. Nuvio does not include games; bring your own complete game folders or supported archives.

## Downloads

Signed APKs will appear under [Releases](https://github.com/GhostNoodl/Nuvio/releases). No release has been published yet.

Ren’Py, RPG Maker, and experimental Windows/Unity playback have different requirements. Compatibility varies by game and device; successful detection or launch does not guarantee full gameplay compatibility.

## Reporting problems

Include your Nuvio version, Android version, device, game/engine version, steps to reproduce, and whether you used touch or a controller. Nuvio’s **Settings → About → Setup, device checks & bug reports** page can prepare a report for you to inspect before sharing.

Do not upload game files, saves, credentials, or private content in issues. Screenshots and reports should be reviewed before posting publicly.

## Updating

Install an official newer APK over the existing app. Do not uninstall first: uninstalling removes app-private data. Export supported save backups before testing updates; Windows/Unity saves need separate manual backup.

Runtime licenses and notices are available inside Nuvio. This release repository does not grant rights to third-party game content.
